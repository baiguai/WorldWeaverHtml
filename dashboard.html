Key Bindings

The dashboard starts in Normal mode. Focusing a panel control switches to Insert mode; press Escape to return.

Normal mode

h / ←
Move to the panel on the left.
l / →
Move to the panel on the right.
k / ↑
Move to the panel above.
j / ↓
Move to the panel below.
i
Enter the current panel and focus its first control.
Enter
Enter the Links panel and select the first link.
b
Choose a directory to import.
c
Copy the generated database to the clipboard.
?
Show this help dialog.
Esc
Clear the link selection and stay in Normal mode.

Links panel

j / ↓
Select the next link while a link is focused.
k / ↑
Select the previous link while a link is focused.
g
Select the first link.
G
Select the last link.
Enter
Open the focused link.

Insert mode

Type
Enter text in the focused textarea or input.
Esc
Release the focused control and return to Normal mode.
